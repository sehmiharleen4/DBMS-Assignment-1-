# Generated plots

Run `python benchmark.py --quick` or `python benchmark.py --full` after Docker Desktop starts. The analysis stage writes these files to `paper/figs/`:

- `fig_latency.pdf` - latency by hop depth
- `fig_scaling.pdf` - latency by graph size at three hops

Copy the files here before pushing the completed repository, or include the complete `paper/figs/` directory. Do not add plots based on invented measurements.
